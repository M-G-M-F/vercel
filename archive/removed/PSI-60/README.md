# PSI-60 (removed 15 November 2026)

PSI-60, "Computational and Experimental Analysis of SPICE Data Sets" (a ground-analysis record with metadata only, no data
files), was removed from the project at the team leader's request. These are its former folders, kept unchanged:

- `flame-in-freefall-kit/analysis/T6/PSI-60_spice-analysis/` (empty T6 package template)
- `flame-in-freefall-kit/data/psi_metadata/PSI-60.json` (NASA PSI API metadata)
- `flame-in-freefall/content/investigations/PSI-60/` (pipeline investigation record)

To restore it, move them back and re-add PSI-60 to the T6 records (see docs/REORGANIZATION_LOG.md, v10.1).
